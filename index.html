🔥 Firebase Setup Guide
Firebase is Google's free cloud platform. The free tier gives you 50,000 reads + 20,000 writes per day — more than enough for any advocate. Takes about 5 minutes to set up.
1Go to Firebase Console
Open console.firebase.google.com → Sign in with your Google account → Click "Create a project"
Name: lextrack → Disable Google Analytics (optional) → Create project
2Add a Web App
In your project → Click "</>" (Web) icon → App nickname: lextrack-web → Register app → Copy the firebaseConfig object shown
3Enable Google Sign-In
Left sidebar → Authentication → Get started → Sign-in method → Google → Enable → Add your email as support email → Save
4Create Firestore Database
Left sidebar → Firestore Database → Create database → Start in production mode → Choose location: asia-south1 (Mumbai) → Done
Then go to Rules tab → Replace with:
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{userId}/cases/{caseId} { allow read, write: if request.auth != null && request.auth.uid == userId; } match /users/{userId}/alerts/{alertId} { allow read, write: if request.auth != null && request.auth.uid == userId; } } }
Click Publish
5Add Authorized Domain (for GitHub Pages)
Authentication → Settings → Authorized domains → Add domain → Enter: aman6539.github.io
6Paste your Firebase Config below
