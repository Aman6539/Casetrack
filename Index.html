🔗 Host on GitHub — Free for Everyone
What you get: A permanent public URL like https://yourname.github.io/lextrack that anyone can open on any laptop, phone, or tablet — no installation, completely free forever.
1
Create a free GitHub account
Go to github.com → click Sign Up → enter email, password, username. It is completely free.
2
Create a new repository
After login → click the green New button → Repository name: lextrack → set to Public → click Create repository
3
Upload this file
In your new repo → click uploading an existing file → drag and drop LexTrack_Free.html → IMPORTANT: rename it to index.html before uploading OR rename after upload → click Commit changes
4
Enable GitHub Pages (makes it a website)
In your repo → click Settings (top menu) → scroll to Pages (left sidebar) → under Source select Deploy from a branch → Branch: main → Folder: / (root) → click Save
5
Get your live URL and share it
After 1–2 minutes → go back to Settings → Pages → your URL appears:
https://YOUR-USERNAME.github.io/lextrack
Share this URL with all colleagues. They open it in any browser on any device.
Important note about data: Each person's cases are saved separately on their own browser (localStorage). Person A's cases on Laptop A will not appear on Laptop B. This is the free version — each advocate manages their own case list independently on the shared URL.
Use Export / Import to share case data: One person can click Export to save a JSON backup file, then send it via WhatsApp to another person, who clicks Import to load those cases on their device.
